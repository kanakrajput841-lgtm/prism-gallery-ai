# Contributing

Thanks for helping improve Prism Gallery AI. Issues and pull requests are welcome.

## Get started

1. Fork the repository on GitHub, or clone it if you have collaborator access.
2. Install Node.js 20.6 or newer.
3. For the basic app, open `index.html` in a browser. To run the local server, run `npm start` and visit `http://localhost:3000`.
4. Optional: copy `.env.example` to `.env` and add your own API keys to try Unsplash and AI descriptions. Never commit `.env` or share API keys.

## Make a change

1. Create a branch for your change.
2. Keep changes focused and follow the existing HTML, CSS, and JavaScript style.
3. Check the relevant features in a browser. If your change uses the server, run it locally as well.
4. Commit your changes with a short, descriptive message.
5. Open a pull request describing what changed, why, and how you checked it. Include screenshots for visible UI changes when useful.

For larger changes, open an issue first so we can agree on the approach. Please don't include private keys, personal photos, or other sensitive data in issues or pull requests.
